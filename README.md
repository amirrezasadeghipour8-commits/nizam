# نظام (Nizam) — داشبورد زندگی شخصی

یک اپلیکیشن وب شخصی، موبایل‌محور و قابل نصب (PWA) برای روتین روزانه، عادت‌ها،
مرور هفتگی و نقشه راه یک‌ساله. تمام رابط فارسی و راست‌به‌چپ است و داده‌ها
**فقط روی همین دستگاه و مرورگر** ذخیره می‌شوند.

اصل راهنما: **کاهش تصمیم‌های غیرضروری، روشن‌کردن اقدام بعدی، حفظ انعطاف، و ساختن
ثبات بدون تبدیل زندگی به مجازات.**

---

## ۱) قابلیت‌ها

- **امروز:** تاریخ شمسی، روز هفته، خوش‌آمد آرام، نوار پیشرفت، برنامه روز به‌صورت
  تایم‌لاین، چک‌لیست روزانه، سه اولویت اصلی، فعالیت بعدی و خلاصه هفته.
- **چک‌لیست روزانه:** هر تکلیف با یک لمس ذخیره می‌شود. وضعیت‌ها: انجام‌شده، در
  انتظار، رد‌شده (بدون انجام‌شدن). امکان افزودن/ویرایش/حذف/جابه‌جایی و افزودن
  کار یک‌باره. سابقه روزهای گذشته هرگز پاک نمی‌شود.
- **سه اولویت روز.**
- **مرور هفتگی:** برنامه‌ریزی‌شده در برابر انجام‌شده، تکمیل چک‌لیست، پیوستگی
  مطالعه/باشگاه/هوش مصنوعی، کارهای عقب‌افتاده، سه پرسش بازتاب و یک تنظیم عملی.
- **نقشه راه یک‌ساله:** چهار فاز از مهر ۱۴۰۵ تا مهر ۱۴۰۶، همه‌چیز قابل ویرایش.
- **یادگیری و پروژه:** مسیر یادگیری گام‌به‌گام، ثبت جلسه‌ها (موضوع، مدت،
  یادداشت، گام بعدی) و کارت پروژه StudyMind.
- **گواهینامه رانندگی:** مراحل قابل ویرایش، تاریخ/هزینه/یادداشت و اقدام بعدی.
- **تنظیمات:** ساعت خواب و بیداری، روزهای دانشگاه و باشگاه، ویرایش کامل برنامه
  روزانه و کارهای تکرارشونده، اهداف هفتگی.
- **پوسته روشن و تیره**، **کارکرد آفلاین**، **پشتیبان‌گیری و بازیابی JSON**.

## ۲) ساختار پروژه

```
index.html                پوسته برنامه
manifest.webmanifest      مانیفست PWA
service-worker.js         کش پوسته برای کارکرد آفلاین
css/styles.css            استایل (روشن/تیره، RTL، موبایل‌محور)
js/jalali.js              تبدیل تقویم جلالی/میلادی و ارقام فارسی
js/defaults.js            برنامه‌ها، کارها، فازها و اهداف پیش‌فرض
js/logic.js               منطق خالص روزها، هفته و آمار
js/store.js               ذخیره‌سازی محلی، پشتیبان و بازیابی
js/app.js                 رابط کاربری و تعامل
icons/                    آیکون‌های PNG و SVG
tools/make-icons.py       بازتولید آیکون‌ها (بدون وابستگی)
tests/tests.js            آزمون منطق (تاریخ، روز، هفته، ذخیره‌سازی)
tests/dom-smoke.js        آزمون دود: اجرای app.js و تعامل واقعی
```

هیچ وابستگی خارجی، سرور، حساب کاربری یا API پولی وجود ندارد.

## ۳) اجرا و آزمایش روی کامپیوتر

از ریشه پوشه پروژه یک سرور ساده اجرا کن:

```bash
python3 -m http.server 8080
```

سپس در مرورگر `http://localhost:8080` را باز کن. (Service Worker فقط روی
`localhost` یا `https` فعال می‌شود.)

آزمون‌ها:

```bash
node tests/tests.js       # ۵۰ بررسی منطقی
node tests/dom-smoke.js   # رندر همه صفحه‌ها + تعامل و ماندگاری داده
```

## ۴) استقرار (Deploy) از روی موبایل

برنامه کاملاً استاتیک است؛ کافی است فایل‌ها روی یک میزبان HTTPS قرار بگیرند.

**راه ساده — GitHub Pages:**
1. در `github.com` یک مخزن عمومی بساز.
2. همه فایل‌ها و پوشه‌ها (با همان ساختار) را از طریق «Add file → Upload files» آپلود کن.
3. در مخزن به Settings → Pages برو و Branch را `main` و پوشه را `/ (root)` انتخاب کن.
4. چند دقیقه بعد آدرس `https://<username>.github.io/<repo>/` آماده است.

**راه سریع‌تر — Netlify Drop:** فایل‌ها را به `app.netlify.com/drop` بکش و رها کن.

هر میزبان استاتیک دیگری (Cloudflare Pages، Vercel و…) هم کار می‌کند.

## ۵) نصب روی اندروید (Samsung Galaxy A55)

1. آدرس سایت را در **Chrome** باز کن.
2. منوی سه‌نقطه (⋮) را بزن.
3. **«افزودن به صفحه اصلی»** یا **«نصب برنامه»** را انتخاب کن.
4. آیکون «نظام» به صفحه اصلی اضافه می‌شود و در حالت تمام‌صفحه باز می‌شود.

پس از نخستین بازدید موفق، دستیار «امروز» آفلاین هم کار می‌کند؛ وضعیت اتصال در
نوار بالا نمایش داده می‌شود. اگر گزینه نصب ظاهر نشد، مرورگر یا محیط فعلی از نصب
PWA پشتیبانی نمی‌کند و سایت در حالت مرورگر هم کار می‌کند.

## ۶) پشتیبان‌گیری و بازیابی

- در **تنظیمات → داده‌ها و پشتیبان‌گیری → دریافت فایل پشتیبان** یک فایل JSON
  دانلود می‌شود. آن را در جای امن (مثلاً فضای ابری خودت) نگه دار.
- برای انتقال به دستگاه دیگر، همان فایل را با **بازیابی از فایل پشتیبان** وارد کن.
- **پاک‌کردن همه داده‌ها** پس از تأیید انجام می‌شود و برگشت‌پذیر نیست.

## ۷) حریم خصوصی

داده‌ها با `localStorage` در همان مرورگر ذخیره می‌شوند. هیچ سرور، حساب یا
سرویس ابری وجود ندارد و اطلاعات **به‌طور خودکار بین دستگاه‌ها همگام نمی‌شود**.
پاک‌کردن داده‌های مرورگر، داده‌های برنامه را هم پاک می‌کند؛ برای جابه‌جایی یا
امنیت از فایل پشتیبان استفاده کن.

## ۸) بازتولید آیکون‌ها

```bash
python3 tools/make-icons.py
```

## ۹) محدودیت‌ها (شفاف)

- همگام‌سازی بین دستگاه‌ها وجود ندارد (عمدی و به‌دلیل معماری محلی).
- یادآوری‌ها/نوتیفیکیشن بخش اصلی برنامه نیستند؛ کارکرد اصلی به آن‌ها وابسته نیست.
- Service Worker روی `file://` کار نمی‌کند؛ برای آفلاین از سرور یا میزبان استفاده کن.
- ارقام برنامه فارسی نمایش داده می‌شوند؛ ورودی‌های عددی مرورگر ممکن است لاتین
  بمانند (رفتار خود سیستم عامل).
