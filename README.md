# نظام — داشبورد زندگی شخصی

داشبورد روزانه‌ای به فارسی: برنامهٔ روز، چک‌لیست، سه اولویت اصلی، مرور هفتگی، نقشهٔ راه یک‌ساله، پیگیری یادگیری و گواهینامهٔ رانندگی.
کاملاً محلی و آفلاین — بدون حساب کاربری، سرور یا پشتیبان آنلاین. داده‌ها فقط در مرورگر همین دستگاه ذخیره می‌شوند.

## اجرای محلی

```
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کن. نصب PWA و سرویس‌کارگر فقط روی `localhost` یا HTTPS کار می‌کنند؛ برای دستگاه تلفن به استقرار HTTPS نیاز داری.

## تست

```
node tests/tests.js        # منطق: تاریخ، هفته‌ها، ذخیره‌سازی، PWA
node tests/dom-smoke.js    # دود: همهٔ مسیرها و چند تعامل
```

## استقرار

۱. فایل‌ها را روی هر میزبان استاتیک (GitHub Pages، Cloudflare Pages و …) بگذار.
۲. در هر تحویل، نام کش را در `service-worker.js` بالا ببر (مثلاً `nizam-shell-v2`) تا پوستهٔ تازه به کاربران برسد.
۳. HTTPS الزامی است؛ بدون آن سرویس‌کارگر علامت نصب PWA کار نمی‌کند. باز کردن با `file://` هم پشتیبانی نمی‌شود.

## نصب روی اندروید

Chrome را باز کن → منوی سه‌نقطه → «افزودن به صفحهٔ اصلی». پس از نخستین بازدید موفق، داشبورد آفلاین هم کار می‌کند.

## پشتیبان‌گیری

همهٔ داده‌ها در همین مرورگر ذخیره می‌شوند. از تنظیمات یک فایل JSON پشتیبان بساز و در جای امن نگهدار؛ برای انتقال به دستگاه دیگر همان فایل را بازیابی کن.
پاک‌کردن داده‌های مرورگر یعنی از بین‌رفتن همهٔ سابقه.

## آیکون‌ها

آیکون‌های PNG با `python3 tools/make-icons.py` ساخته می‌شوند (بدون وابستگی خارجی).
